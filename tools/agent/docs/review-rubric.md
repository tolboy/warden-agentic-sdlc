# Visual / slide review rubric (1–5 each)

Score every slide or screenshot on:

1. **Fill + balance** — useful content covers most of the frame; no large empty waste.
2. **Type size** — body readable (≥ ~18 pt equivalent on slides); titles larger.
3. **Contrast** — text vs background clearly legible.
4. **Fact accuracy** — numbers and claims match the approved source (slides.md / PR / plan).
5. **Image repeats** — cover/finale (or unique shots) not reused incorrectly.
6. **Screenshot quality** — UI callouts large enough to read key controls.
7. **Style unity** — palette, margins, page numbers consistent.

End with **verdict:** `pass` | `changes`, plus concrete must-fix notes (file/slide + what to change).
